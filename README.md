# FGIET Website — React + Vite

A beautiful, fully responsive website for **Feroze Gandhi Institute of Engineering & Technology, RaeBareli** built with React 18, Vite 6 and Tailwind CSS v4.

## Features

- Modern, professional design with smooth animations
- Fully responsive (mobile, tablet, desktop)
- Hero carousel with auto-rotating slides
- Animated stats counters
- Sticky responsive navigation with dropdowns
- Notice marquee + announcement cards
- Course showcase, campus-life cards, footer with contact
- Scroll-to-top button

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Tech

- React 18 • Vite 6
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- react-icons
- Google Fonts (matched to logo): Inter + PT Serif + Noto Sans Devanagari
